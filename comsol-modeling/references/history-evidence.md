## 不能只看节点存在

- T:64–75、R:49–60：材料有 `BHCurve` 属性组，钢针的 AmperesLaw / PassiveConductor 还显式设 `ConstitutiveRelationBH=BHCurve`、`normH_mat=from_mat`。可查证材料属性组与实际本构节点必须一致；这些电磁属性不能推广到热、流、结构接口。
- G:80–93：背景材料 `selection().all()`，之后又赋磁铁材料；必须检查目标域**实际采用**的材料及覆盖/覆盖优先关系，不能只检查“每域都被某材料选择过”。G:75–78 的 `sel_air={1}` 是硬编码历史选择，不是可靠通用方法。
- U:590–610：PassiveConductor 节点存在，但多个已有研究将其列入 `disabledphysics`。已有研究的激活/禁用信息应只读盘点并交接；本 skill 不调整研究来制造“有效”状态，也不能据节点存在宣称旧研究会使用它。
- T:80–81、R:65–66：按最远顶点设置磁标势参考点只是案例算法；必须验证所选点属于所需物理域，不能将最远点规则普适化。
- A:14 和 C:5–6 的 `stored_solutions` 实际由 `m.sol().tags().length` 得到：这是求解器序列标签数，不是通用的“已保存解数据数量”检测。已有求解器节点未必含解，保留旧解也不代表修改后有效。

## 历史记录与假设

- **历史记录** C:1–6：记录 COMSOL `6.3.0.290`、几何包围盒 `33.5,34.5,-0.5,0.5,-45,-5 mm`、一个针域、一个身份配对、零求解器序列标签。N:9–10 描述对应审计和未网格化/未求解状态；本次未重新加载 MPH 复验。
- **静态来源** U:8、14：文件声明由 COMSOL `6.3.0.290` 导出，模型路径指向 ACDC 官方应用目录。它可用于查找当时 API 用法，不证明所有调用在当前模型上成立或模块许可可用。
- M:7–11、26–38、51 将用户暂定直径、未知供货态、17-4PH 对 ER630 的代理、单值无磁滞近似及高场外推分开说明。通用做法是保留来源、单位、适用范围、外推及不确定性；不默认选这种材料，也不自动采用 `40 Hz` 或 `1e6 S/m`。
- N:5–8 区分理想尖端几何与实测、独立物理域与背景等效。H:12–15 区分展示 CAD 与实际物理模型；画出了部件不证明它参与物理，旧解也不能套到新展示几何上。
- H:28–32 的数值、收敛差及历史内部阈值属于特定试算，不能成为通用建模合格标准或本 skill 的验证结果。
- H:3、43–45 明确历史文件不是新授权，并记载 COMSOL 内部失败可能仍返回退出码 0、标记文件写入也可能失败。运行检查不能仅凭退出码或旧标记；应核对本次日志、预期新产物和重新加载审计。
