# 研究、数据传递与网格

先记录：物理时间尺度/长度尺度、目标输出、已有解及其有效性、需要的参数集合、可用模块与版本。下面是决策线索，不是所有任务都运行的固定流程。具体 API 从 official-docs.md 定位。

| 任务 | 配置和检查重点 |
|---|---|
| 稳态 | 有无物理稳态；非线性与耦合强度；初始猜测、变量尺度、残差和约束。可调整阻尼、分离/全耦合、线性求解器或连续延拓；保持最终物理问题，记录延拓路径与终值。 |
| 瞬态 | 物理初始场、初始化一致性、内部时间步、输出时刻、事件与最大步长；输出间隔不代表求解器内部步长。比较步长/容差时对齐输出和初态。 |
| 频域 | 线性化工作点、频率集合、复数相位约定、复幅值/实部/RMS；检查波长、趋肤深度及边界层是否相关，不能只按几何尺寸划网格。 |
| 特征值/特征频率 | 物理接口支持的研究、搜索区域/移位、模态数量、残差、刚体/零模态与模态对应；归一化模态幅值不是实际响应幅值。Eigenvalue 与 Eigenfrequency 不可随意互换。 |
| 参数扫描 | 明确笛卡尔积还是配对参数列表、单位、失败点和完成点；逐点独立初态还是承接上点解，避免路径依赖/滞回被隐含。延拓参数与用户最终目标参数区分。 |

## 步骤间的解来源

写出有向关系，例如 `输入 MPH → 静态研究 stdA/solA → 瞬态 stdB/solB → 数据集 dsetB`。每条边记录被传变量、未求解变量、参数点、源时刻/解索引、坐标/网格映射及实际选择设置。不要假设 sol1 或 dset1 一定正确。

物理初始条件定义系统的初态；求解器初始猜测帮助代数/非线性算法。二者分开记录来源、变量、值/表达式和适用研究。用稳态解初始化瞬态必须符合用户物理意图；不为了收敛擅自替换给定物理初态。独立短程从同一静态解起步不是断点接续。

研究中启停物理、未求解变量取值、多步初始化、延拓路径可能改变方程或实际初态，不能仅因节点位于 Study/Solver 下就视为可自由调整的数值设置。先记录已确认物理问题及这些设置的一致性；未确认则将相应 solve/resume 审查记为 pending 或 blocked。延拓终点必须对应用户目标，不能将修改后的物理问题当作原问题结果。

## 网格证据

- 按薄层、尖端曲率、间隙、边界层、波长、扩散长度等本任务相关尺度设置。局部尺寸要核对选择实体及生效的 hmin/hmax、增长率、曲率/狭窄区控制，不能假设较小 hmax 必然实现。
- 读取网格序列与选择，核对配对/复制面源目标顺序和映射要求。需要先建面后建体的序列，不得先生成相邻体网格后再修改边界网格。
- 生成后保存实际单元类型/数量、自由度、局部表面/域统计、边长分布、质量指标名称与最小值、坏单元位置，必要时导出坐标和连通性散列。整体单元数不能独自证明关键局部加密。
- 记录形函数阶次和曲面几何映射阶次。曲面近似可能影响体积、面积与积分量；可与 CAD/解析几何量核对。阶次改变时网格拓扑可以不变，因此 p 加密应比较自由度与近似空间，而非硬性要求单元数增加。
- 网格敏感性比较实际不同的离散、相同物理与同一定义的输出。实际网格证据完全相同：报告“未形成可用于 h 敏感性的加密”，定位覆盖/选择/最小尺寸约束后再定方案，不能继续计算并宣称网格无关。

## 收敛失败的处置

先区分网格构建、表达式/单位、欠约束、非线性、线性求解器、初态不一致或资源失败。保存首次完整错误与上下文；修改前明确原因和官方依据。若同一策略无新证据仍失败，停止重试并反馈阻塞点。材料缺失、边界条件冲突、运动/物理假设错误交回建模侧；只在授权内调整数值算法。

## 非电磁示例（配置推演，未实机求解）

已建好的导热固体：目标若是规定热源后的温升曲线，可选瞬态；若只求热平衡则考虑稳态。输出可为指定域温度体平均（K）、某边界净热流积分（W），先查真实温度变量和法向热流表达式及正负方向，不把磁电变量搬过来。能量平衡与步长敏感性按目标选择，绝不自行添加对流边界来强求稳态。

已建好的弹性结构：目标固有频率则查 Eigenfrequency，记录约束与零模态、搜索频带和模态序号；输出频率（Hz）和明确归一化的振型。无支撑可能是有意的自由体模态问题，应先核对建模意图，并区分刚体/近零与弹性模态。若确属约束遗漏，返回建模侧，不自行固定一个面；数值移位不能代替物理约束。
