# 结果定义与数值验证

每个输出量先建立记录：名称、表达式与文档依据、单位、参考/空间坐标系、实体维度和选择、数据集/解标签、参数/时间/频率/模态位置、复数分量或相位、统计运算顺序、目标精度和用途。确认选择非空且空间位置正确。

`mean(abs(v))`、`abs(mean(v))`、`sqrt(mean(v^2))`、空间积分及时间 RMS 含义不同；复数 RMS 需明确幅值约定，不直接对复数平方套实数公式。向量平均抵消不表示局部场为零。锐边理想奇异点的最大值可能不收敛，应反馈目标量定义问题，协商有限距离/面积平均等有意义输出，不擅自改几何圆角。

用保存解与匹配数据集提取，核对轴对称积分因子、单位转换、法向符号、参考系及内外侧值。已有表格可能缓存旧解，重新评价前先确认数据源。图注明单位、参数位置、范围、尺度；跨方案比较使用一致色标，不能把插值平滑当解精度。

比较 `getU` 状态向量时先核对 DOF 名称、对应索引和单位；同一物理场也可能附带约束乘子或通量 DOF。不能把整个向量差标成温度等单一物理量，或将不同单位的分量共用一个误差门槛。续算还需核对源解与新解的 DOF 排列；相同网格文件不自动证明向量索引一致。

## 选择最能支撑本次结论的检查

| 检查 | 适用证据及常见误判 |
|---|---|
| 基础 | 有限值、范围/量纲、求解终态、所需实体/时刻/点完整，非有限值不能只丢行处理。进程成功不是此检查通过。 |
| 守恒/解析/基准 | 写清守恒方程、边界通量符号、源项、储能项、积分域；只有物理假设适用才作基准，保存归一化方法。 |
| 网格敏感性 | 真实离散证据 + 对齐目标量；区分空间 h/p 与曲面映射。均值稳定不能推广到局部峰值。 |
| 时间步/容差 | 对齐相同初态和时刻，改变内部步长或容差；采样更密不证明时间积分更准。 |
| 参数点完整性 | 对照计划的参数组合与解索引逐点列成功/失败/缺失，不能仅比较行数。 |
| 周期状态 | 比较相邻周期同相位波形及相关能量/漂移，记录覆盖周期；短时间步长敏感性不证明周期稳态。 |
| 恢复连续性 | 源解一致、恢复前后交界量连续，必要时与不中断参考对照；文件恢复可读不证明可靠接续。 |

门槛来自用户目标、解析/物理尺度或明确标注的工程判断。对接近零的量，用有依据的绝对尺度或混合误差，禁止盲除零；记录比较基准、最大/均方/积分差定义和范围。记录 `passed / failed / not_run / inconclusive / not_applicable`，工程判断不伪装成标准。

验证报告建议 JSON 中分别记录 `calculation_completed`、`basic_checks`、`numerical_convergence`、`experimental_validity`，每项附证据文件和结论范围。只有已完成的验证能提升对应状态；实验有效性需要独立实验依据，默认 `not_validated`。保留未完成检查、失败点和适用时间/参数区间。

## 证据等级与继承

分别标明文档查证、静态检查、模拟执行、独立行为测试、真实 COMSOL 验证。预写的回答/方案仅是示例，关键词匹配仅属文档回归；两者都不能当作独立行为能力证明。只有测试者实际读取原始输入、选择动作并生成过程证据，且未获预写结论，才可报告相应范围的独立行为测试；它仍不代替真实 COMSOL 验证。

输入 manifest 与检查原始模型绑定保持不变。输出记录另关联输入记录、运行 ID、求解 MPH 哈希和本次检查。继承旧检查须另列原检查来源、适用范围、依据和限制，不能把旧 `model_sha256` 改为输出哈希。`legacy.valid` 的模型/来源、节点/解、时间/参数范围及证据都须核对；文件校验器最多支持来源一致，不能宣布旧解的物理或数值有效性。
