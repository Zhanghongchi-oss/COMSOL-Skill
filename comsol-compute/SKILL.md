# COMSOL Compute

接手已建好的模型，先确定本次是**准备、运行、接续还是仅提取**。授权明确就执行范围内工作；历史许可、开发本 skill、准备方案都不是科研求解授权。准备模式只交付配置与入口，标注尚未求解。提取已有解不得隐式重算。

## 接手与边界

优先读取 `model-manifest.json`，按 [交接定义](references/handoff.md) 核验候选 `schema_version=2.0.0`、模型路径与哈希、版本/build、依赖、物理接口、selection_ref、inventory、目标输出及结构化未解决项。共同维护入口为开发工作区 `handoff-review`；技能自带发布副本，运行时不依赖另一个 skill。1.0.0 不自动解释为新协议，迁移另存并保留来源和未知项。只有 MPH 时散列并记录 `pending_model_inspection`，不冒称检查了内部；缺少建模 skill 不阻断独立准备方案。

先列用户所求量的表达式、单位、坐标系、实体范围、时刻/频率/参数点和统计定义；缺少这些会影响结论时先补齐。区分物理初始条件与数值初始猜测。

只修改网格、离散、研究与求解器等数值设置。不得自行改变 CAD 几何、材料本构、物理接口、边界条件或物理初始条件来求收敛。研究中的物理启停、多步初始化及延拓必须符合已确认的物理问题，不能以“研究配置”为由改变问题；物理初态与求解器初猜分开记录。发现建模问题，保存证据并返回建模侧，说明受影响结果及待修项。数值调整记录旧值、新值、原因、文档出处和影响。

## 按需工作

1. **研究与网格**：读 [数值配置](references/numerics.md)。根据物理问题选择稳态、瞬态、频域、特征值或扫描，说明步骤间解来源和数据传递。验证实际生成的网格、局部尺度/质量、配对面顺序、离散与曲面映射；尺寸设置改变不等于实际加密。
2. **API 查证**：遇到新研究、属性或表达式，读 [本机官方索引](references/official-docs.md)，优先查模型对应版本本机文档，再查官方示例。未知属性先定位对象/类型/版本；没有新证据不重复猜属性和重试。编译、属性可写、实际求解通过分别记录。
3. **执行/接续/提取**：读 [执行约定](references/execution.md)、[公共 operation_review](references/operation-review.md) 和 [计算执行审查](references/compute-operation-review.md)。按本次操作及范围产生独立 ready/pending/blocked 审查；ready 不是授权。运行/导出前分别复核审查与当前授权，将声明的实际运行依赖、源解、脚本/class 和实际配置纳入 pins，不能只固定 manifest。准备与检查入口不启动进程。修改后建立新运行，不能复用旧完成状态。接续核对时间/参数位置、初始场、运动状态及解来源；仅提取缺已有解时不得转为求解。
4. **结果与验证**：读 [结果核验](references/results-validation.md)。绑定正确数据集、解序号与选择，区分瞬时、均值、RMS、积分、峰值及奇异点局部值。按目标挑选必要检查，门槛写明用户目标、物理依据或工程判断；不套用历史 1% 等阈值。

二维单域矩形稳态导热任务可按需读取 [小模型适配器及实测修复边界](references/steady-slab.md)，使用随技能发布的案例源码。其单 study、唯一 solver、二维直边三角网格和单邻接域外边界条件是适配器限制，不能作为通用规则。求解器身份来自实际枚举及所属研究；旧解标识、实际 solution_id、solver tag 和载解文件分别核对，歧义或无解时停止。

二维常数材料的稳态焦耳热小例可按需读取 [电热耦合适配器](references/joule-slab.md)。它复用本 skill 的资源、日志、路径和网格检查，额外核对电流、热源、两端散热及供电功率；不把单向耦合验证外推为温度反馈、非线性或瞬态能力。基础实测见 [v3记录](references/live-validation-v3-20261102.md)，新增能力见 [v4深入验证](references/live-validation-v4-20261102.md)，正式瞬态/非线性仅导出与隔离副本使用见 [v5验证](references/live-validation-v5-20261103.md)。

固定域的瞬态导热和保存场接续可按需读取 [瞬态小例](references/transient-slab.md)。接续必须读取实际源末尾时刻/场、保持物理初态不变，并独立核对接缝；保存场重新初始化不等于恢复 BDF 历史或崩溃恢复。温度依赖电导率的双向稳态反馈另读 [非线性电热小例](references/nonlinear-joule.md)，其证据和适用范围单独记录。

## 结论与交付

分别报告：**计算完成 / 基础检查通过 / 数值收敛得到支持 / 实验有效性尚未验证**，列证据、范围和未完成检查。公共合同错误、侧别错误、待办分别呈现；文件合同通过不等于模型正确、执行就绪或授权。退出 0、MPH 存在、旧标记或日志单句均不能单独证明成功。输入 manifest 不变，输出另记输入/输出哈希及本次检查；旧检查保留原绑定，继承另记依据、范围和限制，不能改绑哈希冒充重检。

获授权计算后交付求解 MPH、复现脚本和配置、所需图表/数据、日志、机器可读运行摘要和数值验证结果。只准备则交付配置、计划和执行入口，不制造结果；若缺模型检查、必要任务信息或适配器，应交付可独立完成的方案并标注“方案已准备、可执行运行包未就绪”，不得把未完成骨架当可用入口。保留输入原件；导出应另存。实际能力、未验证项和真实求解测试方案见 [候选能力边界](references/capabilities.md)。
